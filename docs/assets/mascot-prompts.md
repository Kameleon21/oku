Created using the built-in image generation tool. Original PNGs retain their alpha channels. The selected README mascot is the origami page spirit.

## Origami page spirit

![Origami page spirit](mascot-page-spirit.png)

Prompt: Use case: logo-brand. Asset type: original transparent PNG README mascot for Oku, a reading tracker in the terminal. Primary request: an abstract Japanese-inspired origami page spirit, NOT an animal or robot. A single folded cream paper sheet becomes a charming upright little character, with an open-book-like fan fold at its base and one folded corner at the top, two tiny ink-black eyes giving it quiet personality. One restrained vermilion red fold accent. Style: refined contemporary Japanese editorial illustration, flat shapes, subtle washi paper grain, elegant irregular ink details, understated and grown-up rather than glossy cartoon. Palette ONLY warm ivory, charcoal ink, muted vermilion. Strong iconic silhouette readable at 220px, asymmetric folded-paper structure. Centered with generous breathing room, full character visible. Genuine transparent background. No lettering, no Japanese characters, no logo text, no scenery, no animals, no robot parts, no mint, no lavender, no purple, no gradients, no thick cartoon outline, no extra props. The reading/page association must be immediately clear.
