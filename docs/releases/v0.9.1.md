# v0.9.1

Choose and preview themes without leaving Oku.

- Press `T` from any dashboard tab to open the theme picker (leave text inputs with `Esc` first).
- Type a theme name or a few matching letters to filter all 11 existing choices.
- Navigate with arrows, `Ctrl+n`/`Ctrl+p`, or `Tab`/`Shift+Tab` and preview colors immediately across the dashboard.
- Press `Enter` to save the choice to the existing configuration file for future dashboard and CLI sessions. Press `Esc` to restore the previous theme.
- Failed saves leave the picker open with an error so you can retry or cancel.

The existing `oku config theme` commands remain available.

## Release procedure

Merge the feature PR into `develop` after approval and green CI. Then merge
`develop` into `Master` with explicit merge approval, validate the release build,
and tag that release commit `v0.9.1`. The tag supplies the binary version through
GoReleaser and triggers the GitHub release and Homebrew cask update. Verify both
automation results and publish the user-facing notes above as the release body.
See [the development guide](../development.md) for the existing release workflow.
